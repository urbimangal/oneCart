# 🛍️ E-Commerce Website

A full-stack MERN e-commerce web application that provides a seamless online shopping experience with secure authentication, product management, cart functionality, and order processing. Built with a responsive UI and scalable architecture for both users and administrators.

## 🚀 Features

- 🔐 User Authentication (JWT)
- 🛒 Shopping Cart
- 📦 Product Management
- 🔍 Search & Filter Products
- 📱 Fully Responsive Design
- 💳 Secure Checkout
- 👨‍💼 Admin Dashboard
- 📑 Order Management

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- JWT
- Cloudinary

## ⚙️ Installation

```bash
git clone https://github.com/urbimangal/oneCart.git
cd onecart
npm install
```

Start the frontend and backend servers.
